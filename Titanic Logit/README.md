This is an assignment for DSC1107 (Data Mining and Wrangling) on logistic regression.

The objective of this project is to implement logistic regression to build a model that predicts a passenger’s survival status based on the given information, analyze the model’s performance, and interpret the results. The dataset on Titanic passengers was originally retrieved from [Kaggle](https://www.kaggle.com/c/titanic/data?select=train.csv).
